# STBS — Replication code for the validation, robustness and simulation results

**Manuscript:** *A Structural Text-Based Scaling Model for Analyzing Political
Discourse* (PA-2025-0237), Vávra, Prostmaier, Grün & Hofmarcher.

This folder contains the analysis scripts that produce the **Supporting
Information (SI)** results of the revision: robustness checks, face- and
convergent-validity exercises, generative-model and misspecification
simulations, scalability, and the second (Twitter) application. Section numbers
below (S.1–S.7) refer to the Supporting Information.

> These scripts sit **on top of** the core STBS model package
> (`STBS_CAVI/`, available at <https://github.com/vavrajan/STBS>), which
> implements the model (`stbs.py`), the estimation driver and the plotting
> helpers (`plotting_functions.py`). The scripts here import from that package
> via a relative path (`../STBS_CAVI/...`) and read the corpus from
> `STBS_CAVI/data/hein-daily/clean/`.

---

## 1. Requirements

**Python** (3.11 recommended)
- `tensorflow` 2.16 + `tensorflow-probability` (+ `tensorflow-metal` on Apple
  Silicon). Estimation requires the environment variable `TF_USE_LEGACY_KERAS=1`.
- `numpy`, `pandas`, `scipy`, `scikit-learn`, `matplotlib`, `wordcloud`.

**R** (for `05_run_R_plots.R` — the regression summary plots).

**Core package & data (not included here):**
- STBS model package: <https://github.com/vavrajan/STBS> (expected at `../STBS_CAVI/`).
- 114th-Senate corpus (Gentzkow, Shapiro & Taddy): <https://data.stanford.edu/congress_text>
  → `STBS_CAVI/data/hein-daily/clean/` (`vocabulary114.txt`, `author_detailed_info114.csv`, counts).
- DW-NOMINATE (Voteview): <https://voteview.com> (for convergent validity).
- Second application — CongressTweets / Kaggle "US Congressional Tweets"
  (oscaryezfeijo): unzip into `tweets/` (see `23_twitter.py`).

**Large input/output folders are intentionally NOT in this repository**
(they are regenerated by the scripts): `data_simulation/`, `results_simulation/`,
`stbs_cavi_results*/`, `tweets/`, `data_twitter/`. Each script's header
documents the exact paths it reads and writes.

## 2. Core estimation

| Script | What it does | Used for |
|---|---|---|
| `01_estimate_STBS.py` | Estimate STBS on the 114th Senate (TensorFlow/CAVI). Produces the main fit used throughout. | Main paper §3–4; SI S.1 |
| `estimate_STBS_without_party.py` | Same model with the **party** covariate removed from the regression; supports different ideal-point initialisations. | SI S.4.4 (party ablation); R1 #8/#10 |
| `estimate_STBS_twitter.py` | STBS fit on the Senator-tweets corpus. | SI S.7 (second application); R1 #9 |

The main-fit parameters used by the post-processing scripts below are read from
`stbs_cavi_results/…/params/` (and, for the published figures, from the
`originalPolAn_results/…` fit).

## 8b. Excluded from this package (not needed for the SI)

These files exist in the authors' working tree but produce **nothing** that
appears in the final manuscript or Supporting Information, so they are left out
of this replication package:

- `23_twitter_ideal_analysis.py`, `make_twitter_bigram_dtm.py`,
  `candidate_tweets_covariates.csv` — an earlier attempt on a **different corpus**
  (2020 candidate tweets), superseded by `23_twitter.py` (114th-Congress tweets).
- `03_generate_wordclouds.py`, `03b_generate_wordclouds_logscale.py` — legacy
  word-cloud generators; the SI word clouds are produced by the core package, and
  the revision's colour-coded version is `03c_wordclouds_colored_R1.py`.
- `11_iota_explains_ideal.py` — a diagnostic whose output is not reported.

## 9. Typical run order

1. **Core fit:** `01_estimate_STBS.py` (needs `STBS_CAVI/` + hein-daily data).
2. **Main results / face validity:** `05_run_R_plots.R`, `03c_…`, `17_…`,
   `18_…`, `19_…`, `25_…`, `26_…`.
3. **Robustness:** `02_…`/`04b_…` (seeds), `02c_…`/`04c_…` (K),
   `02d_…` (hyperparameters), `run_no_party_two_inits.sh`/`24_…` (party ablation).
4. **Simulations:** `06l_…` → `06m_…`/`06n_…` → `run_*_replicate_fits.sh` →
   `07c_…` → `08_…`/`08d/e/f_…` → `12_…`.
5. **Misspecification:** §6 above.
6. **Scalability:** `13_…` → `13b_…` → `13c_…`.
7. **Second application:** `23_twitter.py` (needs `tweets/`).

Every script has a self-documenting header (inputs, outputs, and a `Run:` line).
`README.txt` (the original developer notes) is kept alongside this file.
